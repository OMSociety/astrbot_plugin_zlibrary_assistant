# ZLibrary Assistant（AstrBot 插件）

> 状态：开发中（M1 骨架已就绪，M2/M3 进行中）

为 AstrBot 提供 Z-Library 图书搜索与下载能力的 LLM 工具集插件。

## 功能

- **zlib_search_books**：关键词搜索图书，返回 HTML 卡片图片（封面/标题/作者/格式/大小）
- **zlib_download_book**：按编号下载图书（账号池轮询，额度管控）
- **zlib_get_status**：账号池健康度与下载额度查询
